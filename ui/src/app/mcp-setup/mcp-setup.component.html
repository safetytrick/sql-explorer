This instance serves an MCP endpoint at {{config.url}}, so Claude Code, Claude Desktop or any other MCP client can ask it about schemas, tables and queries. It is the same data as the pages here, through the same API: nothing to install, only the URL to give.

Everything reads except add_tag and remove_tag. Notes and source loading are deliberately not exposed.

Troubleshooting

Through the tunnel it will not connect. A shared address behind a sign-in page asks a browser to log in, which an MCP client cannot do. Use the endpoint from the machine running SQL Explorer.

@if (config.token) {

401 from the endpoint means the token is missing, expired or revoked: check that {{tokenEnv}} is set where the client starts. A tool that answers "Not allowed" names the permission its token lacks; a token can do no more than both its ceiling and you.

}

An environment served from its cache answers as the pages do: live-only tools such as the DDL ask for a pull first.

Responses are truncated at 60,000 characters, with a note saying so — narrow the request (a schema, a table, a smaller limit) rather than asking for everything.
